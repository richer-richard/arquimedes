This web view previews a stratified catalog of 627 problems across every contest and topic. To query or stream all 1,038,963 problems locally with full-text search, use the CLI or MCP server: 

# Clone & build the local SQLite + FTS5 database
git clone https://github.com/richer-richard/arquimedes.git && cd arquimedes
uv run arquimedes build

# Search 1.04M problems in ~20ms or sample by difficulty (1–10)
uv run arquimedes search "Cauchy-Schwarz" --min-mohs 7.0
uv run arquimedes sample --competition IMO --category geometry

# Export decontaminated train (972k) and eval (10.5k) splits
uv run arquimedes splits
